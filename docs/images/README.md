The `user-guide/` directory contains the current screenshots used by the root README and the [System Usage Guide](../04_SYSTEM_USAGE_GUIDE.md).

| File | Screen |
|---|---|

Screenshots should use test data only, contain no credentials or sensitive veterinary information, and include meaningful alternative text wherever they are embedded.
